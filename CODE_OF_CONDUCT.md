# Code of conduct

Be civil and argue about the work.

## What is expected

Technical disagreement is welcome and is how this project gets better. Bring
the measurement, the failing seed, or the counterexample. "This is wrong" with
a reproduction is a contribution; "this is wrong" without one is an opinion.

Assume the other person read the code and reached a different conclusion for a
reason. Ask what it was.

## What is not

Harassment, personal attacks, and discrimination of any kind. Deliberately
wasting a maintainer's time. Publishing someone's private information.

## Reporting

Report a problem by opening an issue, or privately through GitHub's report
feature if the issue involves a maintainer. Reports are handled by
@hunterinvariants.

The response to a first, minor breach is normally a request to stop. Repeated
or serious breaches end in a block from the repository. There is no appeals
process; this is a small project.
